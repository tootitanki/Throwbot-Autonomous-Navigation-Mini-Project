# Throwbot Autonomous Navigation Mini Project

Simulation work on a small differential-drive robot (Gazebo + Nav2, ROS 2 Humble).

| Folder | What it is |
|---|---|
| `sensor_comparison/` | Dynamic-obstacle detection and avoidance comparison of four sensor conditions, with code, raw results, analysis, diagnostics and screen recordings. |

Rugged-terrain comparison is deferred until the scenario is defined. It is not part of this repo yet.

Everything here is simulation. Nothing is hardware evidence. See `sensor_comparison/README.md` for scope, limits and results.
